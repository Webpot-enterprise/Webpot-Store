🔌 BACKEND INTEGRATION
════════════════════════════════════════════════════════════════════════════════

To connect with your backend API:

Example - Replace hardcoded data with API calls:

In js/script.js, replace the loadUserProfile function:

    // BEFORE (hardcoded):
    function loadUserProfile() {
        document.getElementById('userName').textContent = userData.name;
        // ...
    }

    // AFTER (API call):
    async function loadUserProfile() {
        try {
            const response = await fetch('YOUR_API/user/profile');
            const data = await response.json();
            document.getElementById('userName').textContent = data.name;
            document.getElementById('userPhone').textContent = data.phone;
            document.getElementById('userEmail').textContent = data.email;
            document.getElementById('userWallet').textContent = data.wallet;
            document.getElementById('referralCode').textContent = data.referralCode;
        } catch (error) {
            console.error('Error loading profile:', error);
        }
    }

Similarly update loadOrders function:

    async function loadOrders(filter = 'all') {
        try {
            const url = filter === 'all' 
                ? 'YOUR_API/orders'
                : `YOUR_API/orders?status=${filter}`;
            const response = await fetch(url);
            const orders = await response.json();
            // ... rest of the function
        } catch (error) {
            console.error('Error loading orders:', error);
        }
    }

📞 COMMON ISSUES & SOLUTIONS
════════════════════════════════════════════════════════════════════════════════

Problem: Animations not smooth
Solution: Use a modern browser (Chrome, Firefox, Safari, Edge)
          Animations use CSS3 which older browsers don't support

Problem: Font Awesome icons not showing
Solution: The dashboard uses a CDN for icons - ensure internet connection
          Icons are in the HTML from cdnjs.cloudflare.com

Problem: Referral code copy not working
Solution: Requires HTTPS or localhost for clipboard API
          Works on local file system in modern browsers

Problem: Orders not displaying
Solution: Check js/script.js for ordersData array
          Ensure JavaScript is enabled in your browser
