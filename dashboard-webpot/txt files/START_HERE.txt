🔌 API INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

To connect your backend:

1. Open js/config.js
2. Set your API endpoints
3. Change enableAPI: false → true
4. Update the fetch calls in js/script.js

Example endpoint:
  POST /api/user/profile
  Returns: { name, phone, email, wallet, referralCode }

  GET /api/user/orders?status=all
  Returns: [{ id, date, status, items, total, description }]

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Icons not showing
Solution: Check internet (Font Awesome uses CDN)
          Clear browser cache

Problem: Animations not smooth
Solution: Use modern browser
          Disable other extensions

Problem: Data not updating
Solution: Hard refresh (Ctrl+Shift+R)
          Check browser console (F12)

Problem: Referral copy not working
Solution: Use localhost or HTTPS
          Check JavaScript is enabled
