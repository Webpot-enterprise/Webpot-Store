🎯 COMMON TASKS (Copy & Paste)
════════════════════════════════════════════════════════════════════════════

CHANGE USER NAME:
  In js/script.js, line 1-10, change:
  name: 'John Doe'  →  name: 'Your Name'

CHANGE USER EMAIL:
  In js/script.js, line 1-10, change:
  email: 'john.doe@webpot.com'  →  email: 'your@email.com'

CHANGE WALLET BALANCE:
  In js/script.js, line 1-10, change:
  wallet: '$2,450.00'  →  wallet: '$YOUR_AMOUNT'

CHANGE REFERRAL CODE:
  In js/script.js, line 1-10, change:
  referralCode: 'WP-JD-2024-A1B2C3'  →  referralCode: 'YOUR-CODE'

ADD NEW ORDER:
  In js/script.js, add to ordersData array:
  
  {
      id: 'ORD-009',
      date: 'Jan 12, 2024',
      status: 'delivered',
      items: [{ name: 'Product', quantity: 1, price: 99.99 }],
      total: 99.99,
      description: 'Order description'
  }

CHANGE THEME COLORS:
  In css/style.css, modify :root variables (lines 13-23):
  
  --primary-dark: #0a0a0a;      /* Change this */
  --primary-light: #ffffff;     /* Change this */

DISABLE ANIMATIONS:
  In css/style.css, add to * selector:
  animation: none !important;
  transition: none !important;

📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Icons not showing?
  → Check internet connection (Font Awesome uses CDN)
  → Clear browser cache and refresh

Animations not smooth?
  → Use modern browser (Chrome, Firefox, Safari, Edge)
  → Check CSS animation settings

Referral code copy not working?
  → Use HTTPS or localhost (not file://)
  → Requires modern browser with clipboard API

Orders not showing?
  → Check js/script.js - ensure ordersData is populated
  → Open browser console (F12) for errors
  → Check if JavaScript is enabled

🔌 API INTEGRATION
════════════════════════════════════════════════════════════════════════════

To connect your backend:

1. Open js/config.js
2. Set enableAPI: true
3. Set your baseURL
4. Update API endpoints
5. Modify script.js fetch calls:

Replace:
  const userData = {...}
  
With:
  async function loadUserProfile() {
    const data = await fetch(apiConfig.baseURL + '/user')
    // Update UI with data
  }
