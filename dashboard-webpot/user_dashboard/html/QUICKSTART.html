🎯 Quick Start Guide

1Open the Dashboard

Simply open index.html in your web browser to see the dashboard in action.

The dashboard is fully responsive and works on desktop, tablet, and mobile devices.

2Customize User Data

Edit the userData object in js/script.js:

const userData = { name: 'Your Name', phone: '+1 (555) 123-4567', email: 'your.email@webpot.com', wallet: '$0.00', referralCode: 'YOUR-UNIQUE-CODE' };

3Manage Orders

Update the ordersData array to add or modify orders. Each order includes:

{ id: 'ORD-001', date: 'Jan 10, 2024', status: 'delivered', // or: pending, processing, shipped, cancelled items: [{ name: 'Product', quantity: 1, price: 99.99 }], total: 99.99, description: 'Order description' }

🛠️ Customization Tips

💡 Modify Colors: Edit the CSS variables in css/style.css to change the theme colors globally.
💡 Add New Orders: Simply add new order objects to the ordersData array in js/script.js.
💡 Connect to Backend: Replace the hardcoded data with API calls to your backend server.
💡 Custom Animations: Modify or add new keyframe animations in css/style.css.

🔌 Backend Integration

To connect to your backend API, replace the hardcoded data with fetch calls:

// Example: Fetch user profile from API async function loadUserProfile() { const response = await fetch('/api/user/profile'); const data = await response.json(); document.getElementById('userName').textContent = data.name; // ... update other fields } // Example: Fetch orders from API async function loadOrders(filter = 'all') { const url = filter === 'all' ? '/api/orders' : `/api/orders?status=${filter}`; const response = await fetch(url); const orders = await response.json(); // ... render orders }
